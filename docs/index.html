Key Finding

torch.compile wins the cost–benefit tradeoff

The fp16 + torch.compile pipeline delivers a 2.25× end-to-end speedup with effectively lossless accuracy (IoU ≥ 0.999) and zero infrastructure beyond standard PyTorch. TensorRT matches this at 2.32× but adds ONNX export patches, dynamic-shape engine builds, and a custom runtime — all for a marginal 3% gain. The real bottleneck has shifted: once neural-net inference is fast, Python-side postprocessing (NMS, stability scoring, RLE) dominates wall time.
